Responsive Landing Page – Learnify

About the Project
This project is a responsive landing page for Learnify, an online learning platform. It is designed with an attractive purple theme, a clean layout, and interactive elements to provide a user-friendly experience.

Features
- Responsive design for mobile, tablet, and desktop
- Header and navigation section
- Hero section with an attractive heading and buttons
- Features section highlighting online learning benefits
- About section
- Call-to-action section
- Footer section
- Purple gradient background and modern styling
- Hover effects and scroll animations
- Interactive mobile navigation menu
- Back-to-top button

Technologies Used
- HTML5
- CSS3
- JavaScript
- CSS Flexbox and Grid

How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open the folder in Visual Studio Code.
4. Open `index.html` in your web browser.
5. Alternatively, use the Live Server extension in VS Code.

Project Structure
- index.html – Contains the webpage structure.
- style.css – Contains styling, animations, and responsive layout.
- script.js – Handles interactive features and navigation.
- README.md – Contains project documentation.

Objective
The objective of this project is to learn and practice front-end web development by creating an attractive, responsive, and user-friendly landing page using HTML, CSS, and JavaScript.
